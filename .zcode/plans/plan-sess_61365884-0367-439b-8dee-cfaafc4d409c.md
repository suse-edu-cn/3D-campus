# 四川轻化工大学宜宾校区 3D 地图 — 实施计划

## 一、现状盘点
- `map.osm`(548KB):2388 节点 / 228 ways / 9 relations,含 51 栋建筑(A1-A9 教学楼、B1-B14 宿舍、图书馆、一教、食堂、体育馆、醉泉湖等)、115 条道路、球场/绿地/水域,校区边界 way 698026920。**bbox 略小于实际校区(西南角南大门/运动场被裁),且几乎无建筑高度数据**。
- `宜宾校区地图_副本.png`(2412×1584):官方鸟瞰示意图,用于校准建筑布局/配色/高度,并作为应用内的「平面示意」参考图。

## 二、技术方案(已确认)
- **渲染**:Three.js + TypeScript + Vite,明亮低多边形风(代码生成材质,零外部贴图依赖)
- **投影**:以校区中心为原点的本地切平面投影(米制),北为 -Z,比例精确
- **数据**:构建期预处理成 GeoJSON 静态文件,运行时零网络依赖
- **部署**:`npm run build` → `dist/` 纯静态 → Cloudflare Pages;示意图 WebP 等大素材可选放 R2(公开桶/自定义域名),通过 `VITE_ASSET_BASE` 配置
- **交互范围(已确认)**:基础浏览(旋转/缩放/平移)+ 点击建筑信息面板 + 漫游模式(自动巡游 + 第一人称步行)

## 四、数据管线要点
1. **Overpass 补拉**:扩大 bbox(约 28.795~28.82N, 104.658~104.682E)重导一份完整数据,与你的 map.osm 交叉校验
2. **分层输出**:`buildings / roads(按等级) / water / green / pitch(按运动类型) / boundary / poi(大门、公交站)` 七层 GeoJSON + `meta.json`(中心点、bbox)
3. **高度赋值**:类型默认规则(教学楼 5F、宿舍 6F、食堂 2-3F、厂房单层大空间等,层高 3.2-3.9m)+ 重点建筑手工校准表(一教 7F 按 OSM、图书馆、科学会堂等,对照示意图目测校准),以 OSM id 为键的 overrides 文件
4. **大门与缺失要素**:南大门/东大门/东南门/正大门按示意图定位手工建模(门柱+横梁)
5. 多边形处理:醉泉湖 multipolygon、带中庭建筑(如静苑)用带洞 Shape 三角化

## 五、场景与美术
- **地面**:草绿基底 + 校区内部浅色铺装,道路按等级着色挤出(primary 12m / secondary 9m / service 6m / footway 2.5m)
- **建筑**:ExtrudeGeometry 拉伸 + Canvas 程序化窗户贴图(按层数重复)+ 墙/顶双色;点击时高亮
- **环境**:InstancedMesh 低多边形树(散布于林地/绿地/道路旁)、蓝色水域、红色跑道+绿茵场(按 pitch 类型着色)、大门构筑物、天空渐变 + 雾效 + 方向光阴影
- **标签**:CSS2DRenderer 关键建筑名称标签(可开关、按距离淡出)
- 2.5D 示意图压缩为 WebP 后:开发期对照校准 + 应用内「平面示意」弹窗

## 七、部署方案
- Pages:构建命令 `npm run build`,输出目录 `dist`(数据 JSON 总量约 1-2MB,Pages 自动 gzip/brotli,无需 R2 也能跑)
- R2(可选):创建公开桶 → 上传示意图 WebP 等大素材 → 绑定自定义域名 → 构建时设 `VITE_ASSET_BASE` 指向 R2;提供完整操作文档
- 每阶段以 git commit 打点,方便回溯
